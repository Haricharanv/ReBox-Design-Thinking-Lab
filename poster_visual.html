⚠️  THE PROBLEM
15M parcels/day
5.5B boxes/year
₹20 value gap

Urban residents lack a convenient box-disposal channel while local vendors pay ₹20–35/box for new ones. The scrap ecosystem is optimised for recycling, not reuse — destroying embodied CO₂ worth 1.1 tonnes per tonne of cardboard.

🎯  DEFINE
Problem Statement

Structurally intact e-commerce boxes are destroyed daily through the recycling pipeline while nearby vendors pay ₹20–35 each for new boxes of the same type. No organised infrastructure connects apartment-level box generators with neighbourhood-level box consumers.

POV

Urban residents need a zero-friction disposal channel for packaging, while vendors need a hyper-local, affordable supply — the ₹20 value gap is unaddressed by any existing platform.

How Might We…
"Intercept e-commerce boxes at the apartment level and redirect them to local vendors — making disposal effortless for residents and supply reliable for shopkeepers?"
Design Requirements

Zero-Friction: Disposal in < 2 min, no app download

Physical Bin: Apartment basement — confirmed by all users

Hyper-Local: Vendor pickup radius < 2 km

Cost Savings: ≥ 50% reduction vs. new boxes for vendors
