Define

5 Whys POV Mapping User Journey

Problem Statement

Structurally intact e-commerce boxes are destroyed daily while nearby vendors pay premium for new ones — because zero infrastructure connects box-generators with box-needers at the neighbourhood level.

Root Cause (5 Whys)

  • Landfill waste ← Residents discard boxes.
  • No easy alternative ← Kabadiwala visits are irregular.
  • Kabadiwalas sell by weight ← Crushing boxes is easier/faster.
  • ROOT: scrap ecosystem is optimized for destruction (recycling) rather than redirection (reuse).

Prototype

WhatsApp Bot QR Code Integration Interactive Sim

The Layered Circular Solution

Layer 1: Physical Green Bin 📦

Cardboard-only basement drop-off bins. Provides a zero-friction entry point for residents. Guides signboards for elderly/non-tech users.

Layer 2: WhatsApp Bot + QR Code 💬

Resident scans QR on bin, logs box drops in 15 seconds. WhatsApp bot broadcasts bulk box availability to local vendors.

Layer 3: Analytics Dashboard (Future) 📊

Vendor request broadcasting and diversion metrics tracker for residential community leaderboards.

HMW: "How might we intercept structurally intact e-commerce boxes at the apartment level and redirect them to local vendors who need them?"

3-Tier Solutions Brainstormed

  • Low-Tech: Basement Green Bins, notice boards.
  • Mid-Tech: QR-enabled bins, Twilio WhatsApp bot broadcasts.
  • High-Tech: Mobile App, administrative dashboard.
